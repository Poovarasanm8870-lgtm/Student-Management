# AuraSMS — Next-Gen Student Management System

A premium, full-featured **Student Management System** dashboard built with React + Vite, Tailwind CSS, Framer Motion, Recharts, and Lucide React.

## 🌐 Live Demo
**https://poovarasanm8870-lgtm.github.io/Student-Management/**

## 👥 Role-Based Dashboards
- 👑 **Admin** — Analytics, User Management, System Settings
- 👨‍🏫 **Teacher** — Attendance Logger, Gradebook, Schedule Timeline
- 👨‍👩‍👧 **Parent** — Grades, Attendance Heatmap, Fee Payments, Messages

## 🚀 Tech Stack
- **React + Vite** — Fast modern frontend tooling
- **Tailwind CSS** — Utility-first styling with Dark/Light themes
- **Framer Motion** — Smooth animations & transitions
- **Recharts** — Interactive data visualizations
- **Lucide React** — Premium icon library

## 🛠️ Local Development
```bash
npm install
npm run dev
```

## 📦 Deploy to GitHub Pages
```bash
npm run deploy
```
